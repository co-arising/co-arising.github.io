01

这是什么

围绕同一个理念的一小组 MIT / Apache-2.0 项目：领域描述才是事实来源，代码是它的投影。而不是相反。

F-01

truthsrc——语言与编译器

面向 DDD 的 YAML 真源树语言：12 种原子、15 种工作坊笔记类型、22 种带类型的关系。带硬闸门编译，往返转换逐字节一致，零 npm 运行时依赖。

F-02

一张可以盘问的图谱

每次编译产出本地 SQLite 知识图谱。影响半径、血缘、孤儿、一致性——从 CLI 问、从 MCP 问，或者在浏览器里问。

F-03

带收据的代码生成

生成可编译的 CQRS/ES Scala 代码库。每个生成文件都携带锚点：它来自哪个知识节点、哪个字节区间，一清二楚。verify-project 会重新证明这一点。

F-04

刻意保留的手写区

端口是生成的；行为填在物理隔离的手写模块里。银行示例中的 35 个手写文件是完整实现，不是占位桩。

F-05

智能体可用，但有守护纪律

一个 MCP 服务器暴露 26 个只读工具，让编码智能体查询图谱，而不是到处 grep。智能体起草，人类定夺。真源树是唯一的知识编辑面；技术绑定与手写实现各有独立职责。

F-06

构造性地诚实

没做完的东西在台账上，不在营销话术里。独立体验、公开材料交付、托管与 BDD 衍生物——全部与技术验收分开追踪。

02

快速开始

在新的练习目录中使用 Node ≥ 22.13。取得工具源码需要网络；Counter 生成闭环不需要 JVM 或数据库服务。包含银行示例与 MCP 集成的完整教程在实战指南。

export TRUTHSRC_WORKSPACE="$PWD"
git clone https://github.com/co-arising/metarch-truthsrc.git
export TRUTHSRC_CLI="$TRUTHSRC_WORKSPACE/metarch-truthsrc/bin/truthsrc.js"
node "$TRUTHSRC_CLI" init counter-lab --format human
cd counter-lab
node "$TRUTHSRC_CLI" generate-project --project truthsrc.project.json --out generated --plan --format human

理解

为何是 co-arising，而非本体论

聚合不是你画在图上的类——它是当命令、事件、状态与守卫在不变量约束下共同成立时所「缘起」的结构。附基于真实银行数据的交互式消解演示。

 理解

真源树语言

战略层与范围层：限界上下文、子域、22 条关系的注册表、治理闸门，以及银行树的真实切片。

 看它工作

真源树 → 代码 → 回得来

六个阶段，每段都有精确命令和经核实的闸门数字：编译、图谱、生成、锚点验证、手写区、再验证。
