别信我们——自己重建

你刚刚查询的文件是一份派生缓存。从银行仓库复现它（Node ≥ 22.13）：

git clone https://github.com/MadPolaris/bank-wealth-demo.git
cd bank-wealth-demo && npm install --no-save
node ../metarch-truthsrc/bin/truthsrc.js graph --tree truth/bank-wealth --out my-copy.sqlite
