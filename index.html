01

What this is

A small family of MIT / Apache-2.0 projects around one idea: the domain description is the source of truth, and code is its projection. Not the other way around.

F-01

truthsrc — the language & compiler

A YAML truth-tree language for DDD: 12 atom kinds, 15 workshop note types, 22 typed relations. Compiles with hard gates, roundtrips byte-identical, zero npm runtime dependencies.

F-02

A graph you can interrogate

Every compile produces a local SQLite knowledge graph. Ask blast radius, lineage, orphans, consistency — from the CLI, from MCP, or in your browser.

F-03

Code generation with receipts

Generates a compiling CQRS/ES Scala codebase. Every generated file carries an anchor: the exact knowledge node and byte span it came from. verify-project re-proves it.

F-04

A handwritten zone, by design

Ports are generated; behavior is filled in a physically separate handwritten module. 35 handwritten files in the bank example are complete implementations, not stubs.

F-05

Agents, but with stewardship

An MCP server exposes 26 read-oriented tools so coding agents query the graph instead of grepping. Agents draft; humans decide. The tree is the only knowledge-editing surface; explicit technical bindings and handwritten implementations have separate responsibilities.

F-06

Honest by construction

What isn’t done is on the ledger, not in the marketing. Independent experience, public material delivery, hosting and BDD derivatives — all tracked separately from technical acceptance.

02

Quickstart

Use Node ≥ 22.13 in a new exercise directory. Acquiring the source checkout needs a network; the Counter generation loop needs no JVM or database service. The full walkthrough — including the bank example and the MCP integration — is on the hands-on guide.

export TRUTHSRC_WORKSPACE="$PWD"
git clone https://github.com/co-arising/metarch-truthsrc.git
export TRUTHSRC_CLI="$TRUTHSRC_WORKSPACE/metarch-truthsrc/bin/truthsrc.js"
node "$TRUTHSRC_CLI" init counter-lab --format human
cd counter-lab
node "$TRUTHSRC_CLI" generate-project --project truthsrc.project.json --out generated --plan --format human
node "$TRUTHSRC_CLI" generate-project --project truthsrc.project.json --out generated --format human
node "$TRUTHSRC_CLI" query-project --project truthsrc.project.json --out generated --knowledge SetCount --format human
node "$TRUTHSRC_CLI" verify-project --project truthsrc.project.json --out generated --format human
