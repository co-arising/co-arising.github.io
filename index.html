01

What this is

A small family of MIT / Apache-2.0 projects around one idea: the domain description is the source of truth, and code is its projection. Not the other way around.

F-01

truthsrc — the language & compiler

A YAML truth-tree language for DDD: 12 atom kinds, 15 workshop note types, 22 typed relations. Compiles with hard gates, roundtrips byte-identical, zero npm runtime dependencies.

F-02

A graph you can interrogate

Every compile produces a local SQLite knowledge graph. Ask blast radius, lineage, orphans, consistency — from the CLI, from MCP, or in your browser.

F-03

Code generation with receipts

Generates a compiling CQRS/ES Scala codebase. Every generated file carries an anchor: the exact knowledge node and byte span it came from. verify-project re-proves it.

F-04

A handwritten zone, by design

Ports are generated; behavior is filled in a physically separate handwritten module. 35 handwritten files in the bank example are complete implementations, not stubs.

F-05

Agents, but with stewardship

An MCP server exposes 26 read-oriented tools so coding agents query the graph instead of grepping. Agents draft; humans decide. The tree stays the only editing surface.

F-06

Honest by construction

What isn’t done is on the ledger, not in the marketing. Full-service runtime gates, hosting, BDD derivatives — all tracked with IDs.

02

Quickstart

Node ≥ 22.13 is the only requirement. No JVM, no database, no network. The full walkthrough — including the bank example and the MCP integration — is on the hands-on guide.

# 1 · get the toolchain (source checkout; npm release is on the ledger)
git clone https://github.com/co-arising/metarch-truthsrc.git
npm install --prefix metarch-truthsrc

# 2 · create your first project and look at the plan before anything is written
node metarch-truthsrc/bin/truthsrc.js init counter-lab --format human
cd counter-lab
node ../metarch-truthsrc/bin/truthsrc.js generate-project --plan --format human

# 3 · generate, then ask where a rule lives in the generated code
node ../metarch-truthsrc/bin/truthsrc.js generate-project --format human
node ../metarch-truthsrc/bin/truthsrc.js query-project --knowledge SetCount
