Fit, not a feature contest

Where does this fit
in your existing workflow?

Keep tools that help your team discover, describe and operate a domain. Consider a truth source when you also need a reviewable connection from declared behavior to generated implementation and back. That is a particular job, not a replacement for every modeling or data platform.

02

Existing standards, explicit implementation status

The standards already exist. A sensible mapping onto one is not the same as an implemented, tested exporter. The current interfaces below are distinct from proposed derivatives.

Available interface

SQLite knowledge graph

A local graph representation supports real queries. The Explorer reads the shipped bank snapshot F-03; it is not a live view of your repository.

Available interface

MCP access

The toolchain provides read-oriented tools over stdio JSON-RPC F-16. This is a query interface, not an export to every standard listed below.
