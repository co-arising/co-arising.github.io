02

Don’t trust us — rebuild it

The file you just queried is a derived cache. Reproduce it from the bank repo (Node ≥ 22.13):

git clone https://github.com/MadPolaris/bank-wealth-demo.git
cd bank-wealth-demo && npm install --no-save
node ../metarch-truthsrc/bin/truthsrc.js graph --tree truth/bank-wealth --out my-copy.sqlite
# compare node/edge counts with the fingerprint panel above
DEGRADE GRACEFULLY

If the sqlite file fails to load (offline first visit, very old browser), the presets fall back to their documented expected answers so the page still teaches the query semantics.
