Canonical graphstore

Project knowledge/anchor graph
Knowledge and generated-location mappings from a matching project and output. Code queries require that project's identities, precision and freshness.
Workshop project-view export
A browsing export that may be truncated: the 2026-11-06 snapshot contains 120 nodes / 183 edges from declared totals of 861 / 737 (F-17), not a complete copy of either database.

Literal, case-insensitive ID/name substring search (SQLite’s case folding is ASCII); kind and search combine. Filters never change the selected node. All nodes are reachable in pages of 40; each fresh-copy query is cancelled after 5 seconds. SQL drafts are never shared in node URLs.

    Results follow modeled edges only. Impact traversal does not prove complete dependency coverage; raw aliases, documentary sources and canonical semantics are distinguished.

    Or write SQL below and hit Run. Everything executes against the in-memory copy of the bank graph.

    Disposable SQL sandbox

    Each run uses a fresh local copy. SQL is real; changes are discarded and cannot affect presets. Limits: 16 KiB SQL, 4 result sets, 200 rows per set, 32 columns, 8 KiB per cell, 512 KiB response; cancellation after 5 seconds. Later statements may not run after truncation.

    Don’t trust us — rebuild it

    This graphstore is a derived snapshot, not the project knowledge/anchor database. First complete the guide’s tool setup in the same shell, then point BANK at your existing matched bank checkout. The output below must be a new file. Current-source counts can differ from this dated snapshot; count equality alone does not establish byte identity.

: "${BANK:?Set BANK to your matched bank checkout absolute path}"
