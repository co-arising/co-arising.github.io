The language · strategic & scope layers

A description language for the truth tree

One YAML tree is the only authoring surface: workshop notes flow in through an inbox, formal atoms hold the compiled contract, and a registry of 22 typed relations is the metamodel. This page publishes the language’s strategic layer (contexts, subdomains, the map) and scope layer (kinds, relations, gates). Visual authoring tooling is on the ledger.

RULE ZERO

The author tree is the only editing surface. Everything downstream — the compiled canonical, the knowledge graph, generated code, ledgers, anchors — is derived and regenerated. Hand-edited derivations are void by contract. That single rule is what makes every other guarantee possible.

04

A real slice, unedited

From truth/bank-wealth/…/credit-balance/slices/initialize-account.slice.yaml. This is the language in its densest form: one command, five guards, one event, folds, provenance.

kind: slice
aggregate: CreditBalance
command: InitializeAccount
payload:
  {
    "name": "InitializeAccount",
    "parameters": [
      "resource: AccountId @BUSINESS_INPUT",
      "currency: String @BUSINESS_INPUT",
      "amount: Money @BUSINESS_INPUT"
    ],
    "guards": [
      "@guard[invariantRef](reject ACCOUNT_ID/ACCOUNT_ID: \"param.resource == state.id\")",
      "@guard[invariantRef](reject ACCOUNT_CURRENCY/ACCOUNT_CURRENCY: \"param.currency == \\\"CNY\\\" …\")",
      "@guard[invariantRef](reject ACCOUNT_INIT_ONCE/ACCOUNT_INIT_ONCE: \"!state.initialized\")",
      "@guard[invariantRef](reject ACCOUNT_SEED_NONNEGATIVE/ACCOUNT_SEED_NONNEGATIVE: \"param.amount.amount >= 0.00\")"
    ],
    "produces": [ "AccountInitialized" ],
    "provenance": { "author": "agent-assisted-bank-v1", "approvedBy": "user-approved-p24-p25-bank-joint", … }
  }
events:
  {
    "AccountInitialized": {
      "payloads":  [ "resource: AccountId @PROPAGATED", "amount: Money @PROPAGAGED", … ],
      "bindings":  [ "resource <- param.resource", "amount <- param.amount", … ],
      "foldAssignments": [
        "initialized := \"literal:true\"",
        "accountBalance := @fold[put](key=event.currency, value=event.amount)"
      ]
    }
  }
Guards

Rules with teeth

Each guard cites a named invariant (ACCOUNT_SEED_NONNEGATIVE) and an error code to reject with. “Non-negative balance” is no longer a comment — it compiles into the generated command handler.

Bindings

Where payloads come from

Every event field is either propagated from a parameter or computed — provenance at the field level, which is what read-model lineage (R10/R11) builds on.

Folds

History becomes state

foldAssignments define how the event updates aggregate state — the algebra the generated event applier implements.

05

Governance: three gates, not style guides

validate — 0 hard findings

structural + semantic validation of the author tree

Unknown kinds, dangling references, an event defined in two places, a slice without its aggregate — all hard findings. Zero is the only acceptable count. Bank tree as of 2026-11-11: 0 hard verified.

roundtrip — byte-identical

tree → canonical → tree must reproduce the author files exactly

This is the anti-formatting-drift gate. If compilation “normalizes” anything, the roundtrip diverges and the gate fails. Bank tree: 157 atoms, byte-identical verified.

compile-products — strict contracts

formal products must satisfy their schemas before use

Ports, saga IR, execution IR: typed, versioned products compiled from the tree with their own validation. Generated code consumes frozen products only.

AGENTS

The editing contract for AI agents is the same three gates plus stewardship rules: every batch ends validate AND roundtrip green; payload text is preserved verbatim; no tool artifacts inside the tree; one event defined in exactly one slice. It ships with the toolchain as AGENTS.md and a query skill pack.

What authoring looks like today — and tomorrow

Today the editing surface is YAML files plus three extraction skills (from a codebase, from reachable data, from a one-line description). Visual authoring — importing workshop boards from Qlerify or Miro, reverse-engineering a tree from an existing repo — is designed for but not yet built: DEF-02.
